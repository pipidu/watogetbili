# 哔哩哔哩进度同步

一起看用的油猴脚本，外加一个带管理页面的 PHP 后端。建一个房间，大家的播放进度默认跟着房主。房主可以授权某个成员调整进度，或更换正在播的视频。

## 功能

- 创建房间、用 6 位房号加入
- 视频和播放进度默认同步房主，暂停、拖动、倍速都会跟上
- 房主可以移交房主、移出成员
- 房主可以给单个成员授权「调整进度」或「更换视频」，也可以对全员开放
- 被授权的成员操作后，会暂时成为进度的同步源，直到房主自己再操作
- 后端地址写在脚本面板里，不写死
- 管理页用网页配置 MySQL，自动建库建表

## 后端

需要 PHP 8.0 以上，并启用 `pdo_mysql`。数据库用 MySQL 5.7+ 或 MariaDB 10.3+。

1. 把 `sync.php` 上传到网站目录。
2. 用浏览器打开它，例如 `https://example.com/sync.php`。
3. 在初始化页面填写数据库主机、端口、库名、账号、密码、表前缀，以及管理员账号。保存后会尝试建库建表。
4. 概览页上的「接口地址」就是脚本里要填的后端地址。

数据库账号需要能读写目标库。有建库权限时，不存在的库会自动创建；没有的话，请先自己建好空库再填库名。

`127.0.0.1` 走 TCP，`localhost` 在很多机器上走的是本机套接字，填错会连不上。

配置写在 `sync.php` 旁边的 `bili-sync-private/config.php`，不要把这个目录公开到网上。Apache 会用脚本生成的 `.htaccess` 拒绝访问。Nginx 需要自己加一条：

```nginx
location ^~ /bili-sync-private/ {
    deny all;
}
```

管理页可以改数据库、人数上限、掉线清理时间，也可以查看和删除房间。成员权限在视频页的脚本里由房主设置。

## 脚本

用 [Tampermonkey](https://www.tampermonkey.net/) 或 Violentmonkey 新建脚本，把 `bilibili-sync.user.js` 全部贴进去。第一次跨域请求时，允许脚本访问你的后端域名。

脚本匹配这些页面：

- `https://www.bilibili.com/video/*`
- `https://www.bilibili.com/bangumi/play/*`
- `https://m.bilibili.com/video/*`
- `https://m.bilibili.com/bangumi/play/*`

打开任意视频，在右上角「一起看」面板里：

1. 填后端地址和昵称，点「测试连接」，再点「保存」。
2. 房主点「创建房间」，把房号发给朋友。
3. 其他人打开任意视频，输入房号加入。页面会切到房主正在看的视频，并跟上进度。
4. 房主在成员旁边勾选「单独授权进度」或「单独授权换视频」。也可以打开「全员可调进度」「全员可换视频」。
5. 需要换人当房主时，点「移交房主」。

浏览器可能拦住自动播放。面板上出现「点击这里开始同步播放」时点一次即可。

有换视频权限的人，如果刷新后停在另一个视频页，房间会跟着换成这个视频。没有权限的人会被拉回房间里的那一集。

## 本地预览面板

不装油猴时，可以用 PHP 内置服务器看管理页和脚本面板。内置服务器是单线程的，只适合自己试，真人和朋友一起看请放到 Apache、Nginx 或 php-fpm 上。

```bash
php -S 127.0.0.1:8765 -t .
```

- 管理页：<http://127.0.0.1:8765/sync.php>
- 面板预览：<http://127.0.0.1:8765/tests/harness.html>

预览页不是哔哩哔哩，不能在那里创建房间，但可以测连接、加入已有房间。

## 自测

```bash
php sync.php unit
node --test tests/canonical.test.mjs
BILI_SYNC_BASE=http://127.0.0.1:8765/sync.php php tests/api_test.php
```

接口测试会删掉并重建数据库 `bili_sync_test`，也会清掉本地的 `bili-sync-private` 配置。
